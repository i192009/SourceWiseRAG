# SourceWiseRAG

What is included:
- FastAPI backend
- Streamlit frontend
- SQLite metadata store
- Milvus vector storage integration
- Ollama generation client
- SearXNG web-search fallback
- Persistent conversations, auth, audit logs, and chat file attachments
